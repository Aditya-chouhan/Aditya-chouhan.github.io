What broke, and what I did about it

Anyone can make a demo work once. These are the moments each system actually ran and didn't — and the fix, with the receipt.

Salesforce: the first real test run came back 19/20, not 20/20.

A scheduled Apex job's execute() runs synchronously under Test.stopTest(), but the batch job it enqueues doesn't reliably finish before the assertion checks it — a real platform race, not a bug in the rollup logic. Root-caused and split into two deterministic tests rather than retried until green. Re-run: 20/20, 96% coverage.

See the test output →

n8n: the error handler I built to catch failures was itself broken.

n8n rewrites a thrown error's name before the handler sees it, so the classifier I wrote never matched a code defect and fell through to "unclassified." It still paged — the conservative default held — but the rule was wrong. Only surfaced by deliberately breaking a live workflow and reading what actually arrived.

See the failure + handler run →

A stale number was leaking into outreach email.

A signal-detection demo pulled every fact live, then pasted a hardcoded "+183%" — in the one output designed to be sent to a real person. Re-running it returned a materially different number. Now computed at run time from the same function the score uses, and the page states both figures with their dates.

See the repo →

"Clone it and run it" didn't actually work.

A CRM lifecycle system used syntax that needs Python 3.10+, with no minimum version stated — and macOS still ships 3.9. The documented reproduce steps failed at step one for anyone following them, on my own machine included. Fixed; outputs then verified byte-identical to what was already committed, so the numbers were always real — they just couldn't be regenerated until this was found.

See the repo →

I audited my own published precision number, and it needed two corrections.

Groundtruth reports 60.5% precision on 43 samples. The 95% confidence interval is 28 points wide, and 65% of the sample is one repository — the point estimate was never wrong, but alone it implied more than the sample supports. Caught by a measurement tool built for exactly this, then run across the rest of the portfolio.
